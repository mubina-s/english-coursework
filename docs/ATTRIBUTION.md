## Public Portfolio Cleanup

The original course archive contained additional drafts, planning worksheets, personal reflections, a final portfolio, and a large multimodal video.

Those materials were intentionally excluded from this public GitHub version when they were repetitive, contained unnecessary personal information, were too large for a practical GitHub portfolio, or did not add enough value to the curated presentation.

The purpose of this repository is to showcase selected communication work while preserving academic integrity and accurate attribution.
