## 🔎 About This Repository

This repository contains **selected coursework from ENGL 2500 and ENGL 3140 at Iowa State University**.

The work here reflects my development in written, visual, and professional communication. I selected assignments that best demonstrate research, rhetorical analysis, technical writing, usability analysis, and communication for specific audiences.

This is a **coursework portfolio**, not a single standalone project.

---

## 📚 ENGL 2500

Selected ENGL 2500 work focuses on academic research, rhetorical analysis, and communicating complex topics clearly.

### 📝 Rhetorical Analysis

An analysis of an opinion essay about social media, technology, artificial intelligence, and changing online platforms.

The assignment strengthened my ability to examine:

- Audience and purpose
- Credibility and rhetorical appeals
- Evidence and source use
- Author perspective
- Technology-focused communication

### ⚖️ Research Project — Corrections System Reform

A research-based paper examining challenges in the U.S. correctional system and approaches to reform, including mental health care, rehabilitation, recidivism reduction, reintegration, and international models.

This project strengthened my skills in:

- Research synthesis
- Source-based argumentation
- Academic organization
- Evidence evaluation
- Writing about complex social-policy issues

## 🧩 ENGL 3140

Selected ENGL 3140 work focuses on **professional and technical communication**, with several assignments directly connected to technology and cybersecurity.

### 🔐 Multi-Factor Authentication User Manual

An individual technical user manual explaining Multi-Factor Authentication for Iowa State University users.

The manual covers:

- What MFA is and why it matters
- Authentication methods
- Microsoft Authenticator
- Phone-based authentication
- Security keys
- Account-security considerations
- Troubleshooting and user guidance

This assignment gave me experience translating a cybersecurity concept into documentation designed for a non-specialist audience.

### 🏢 Student Innovation Center Usability Proposal

An individual proposal for conducting a usability study of the Student Innovation Center scheduling website.

The proposal focused on:

- User navigation
- Reservation workflows
- Scheduling clarity
- Audience needs
- Usability problems
- Practical recommendations for evaluation

### 👥 Usability Study Recommendation Report

A team usability study of the Student Innovation Center scheduling website.

The project evaluated how users completed common scheduling tasks and identified areas where navigation, room rules, booking information, and responsibility labels could be clearer.

The team produced both:

- A formal recommendation report
- A recommendation report presentation

Because these are **team submissions**, they are clearly identified as collaborative work in this repository.
